# #45 找出煩惱的根源

## 使用指南（編輯補充）

- **適用情境：**希望從表面煩惱轉成針對原因的發想題目。
- **需要的資訊：**煩惱、現象證據與已嘗試的解法。
- **有用的產出：**候選根因、證據狀態與對應的開放問題。
- **使用提醒：**7 個原因與各 3 題是原文規模；不能為湊數把假設說成確定根因，必要時提出如何排除假設。

指南用於選擇及調整方法；以下區塊逐字保留使用者提供的原文。原文中的填入欄位於執行時代入，不改動保存版本。共同執行原則見 [SKILL.md](../../SKILL.md)。
