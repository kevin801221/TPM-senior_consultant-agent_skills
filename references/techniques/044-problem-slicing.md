# #44 分割煩惱

## 使用指南（編輯補充）

- **適用情境：**問題過大或混合多種情境，難以形成可處理的題目。
- **需要的資訊：**原始煩惱與發生的時間、場所及條件。
- **有用的產出：**按時間、空間或條件切出的題目，以及優先處理的一片。
- **使用提醒：**切片是縮小探索範圍，不保證消除跨情境的共同原因。

指南用於選擇及調整方法；以下區塊逐字保留使用者提供的原文。原文中的填入欄位於執行時代入，不改動保存版本。共同執行原則見 [SKILL.md](../../SKILL.md)。
