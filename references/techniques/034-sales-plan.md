# #34 擬定銷售計畫

## 使用指南（編輯補充）

- **適用情境：**需要把新事業的收入、成本與人力假設連成月度模型。
- **需要的資訊：**定價、客戶成長、轉換、流失、成本、人力與起始月份；未知項可設明示假設。
- **有用的產出：**18 個月的可追溯月表、計算關係、情境與主要敏感變數。
- **使用提醒：**把輸入假設與計算結果分開，核算營收和損益；沒有實際資料就稱為情境試算，不當作已驗證預測。
