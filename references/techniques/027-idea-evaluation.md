# #27 評估創意效益

## 使用指南（編輯補充）

- **適用情境：**需要比較候選創意的效益與可行性。
- **需要的資訊：**候選方案、評估目的、尺度與已有證據。
- **有用的產出：**同一尺度下的評分理由、主要未知與會改變排序的條件。
- **使用提醒：**1～10 分不是客觀測量；避免無依據的小數精度，資訊不足可用範圍或暫不評分。
