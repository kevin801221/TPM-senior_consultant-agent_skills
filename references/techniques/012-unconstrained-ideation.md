# #12 不設限的發想

## 使用指南（編輯補充）

- **適用情境：**過早受限於資源，需要先描述理想體驗。
- **需要的資訊：**發想對象與希望創造的價值。
- **有用的產出：**理想狀態，以及值得帶回現實限制下測試的核心想法。
- **使用提醒：**暫時移除限制是思考實驗，不是實際執行時忽略法規、成本或風險的理由。

指南用於選擇及調整方法；以下區塊逐字保留使用者提供的原文。原文中的填入欄位於執行時代入，不改動保存版本。共同執行原則見 [SKILL.md](../../SKILL.md)。
