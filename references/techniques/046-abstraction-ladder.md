# #46 煩惱的抽象化

## 使用指南（編輯補充）

- **適用情境：**卡在特定解法，想回到更上位的目的重新出題。
- **需要的資訊：**具體煩惱、受影響者與情境。
- **有用的產出：**輕、中、高抽象程度的題目，及仍能回到情境的切入點。
- **使用提醒：**抽象化不是移除所有限制；過度抽象時返回使用情境，避免只剩宏大口號。
